## Changed
- Homepage opening now invites curiosity about shared AI questions rather than sales-like conversion.

- Additive CSS enhancements for hero readability, reduced-motion accessibility and focus visibility.
- Removed scripts/trace.js and its references: the /api/trace endpoint cannot run on static GitHub Pages and the previous script silently stored visitor behavior in localStorage. Analytics require an explicit privacy-reviewed backend and consent model.
